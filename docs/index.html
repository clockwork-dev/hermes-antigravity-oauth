EXECUTION TOPOLOGY

How the Plugin Bridges Hermes to Google Antigravity

From user prompt to local IPC, through the official CLI daemon, to Google Cloud inference. Select a step or inspect the real payload envelopes passed between system boundaries.

STAGE 01 Local Host

Hermes Turn Runner

Accepts user prompt from CLI or chat interface. Resolves active model configuration and dispatches to plugin profile.

Caller: hermes chat
STAGE 02 In-Process

AntigravityOAuthProfile

Normalizes model IDs, translates reasoning effort flags, and verifies that the local OAuth session state is active.

Module: plugin.py
STAGE 03 Subprocess IPC

agy Worker Pipe

Persistent warm subprocess. Streams NDJSON payloads across stdin/stdout, handles OAuth token refresh without UI prompt.

Protocol: stream-json
STAGE 04 Egress gRPC

Google Cloud Ingress

Direct connection to Antigravity API endpoint with user OAuth bearer token. Zero intermediary proxies or telemetry leaks.

Endpoint: cloudcode.googleapis.com

DATA PRIVACY & AUDIT

Zero-Exfiltration Architecture

Why enterprise security teams and local developers trust this plugin. OAuth credentials never leave your filesystem.

01

Direct-to-Google OAuth PKCE

Authentication uses RFC 7636 Proof Key for Code Exchange via your default local browser. The OAuth token exchange occurs directly with Google accounts servers.

02

No Intermediary Relays

No telemetry collector, analytics ping, or middleman proxy sits between Hermes Agent and Google Cloud. Tokens are read from the standard local OS keyring or encrypted config file.

03

Auditable Open Source Code

The entire plugin is implemented in Python without obfuscated bytecode or binary shims. Every network socket call can be audited via standard system tools.

STEP-BY-STEP SETUP

Installation & Verification

Choose your installation method. Both methods pass hermes plugins validate with zero warnings.

METHOD 1 (RECOMMENDED) Hermes Native

Install via Hermes Plugins Manager

Hermes clones and links the plugin directly from GitHub into its active plugin directory.

1. Install and enable:
hermes plugins install clockwork-dev/hermes-antigravity-oauth --enable
2. Launch interactive chat with Pro model:
hermes chat -m antigravity/gemini-2.5-pro
METHOD 2 (MANUAL DEV) Git & Local Link

Clone and Link Locally

Ideal for plugin development, inspecting unit tests, or custom profile modifications.

Linux / macOS / WSL:
git clone https://github.com/clockwork-dev/hermes-antigravity-oauth.git ~/.hermes/plugins/antigravity
hermes plugins enable antigravity
Run unit test suite:
pytest tests/ -v
