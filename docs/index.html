hermes auth add antigravity-oauth

Technical Benchmarks

Built for Speed and Zero Token Leakage

⚡

Warm Worker vs. Oneshot Cold Starts

Legacy SDKs launch agy from scratch on every turn, triggering full language server startup (~1.5–2.5s overhead). Our plugin maintains a hot background worker over bidirectional JSON streams, streaming replies without initiation lag.

Subsequent Turn TTFT < 250ms latency
🔒

Isolated Profile & Zero-Exfiltration

Instead of sharing your personal desktop ~/.gemini configuration, Hermes uses an isolated profile root (~/.hermes/antigravity-oauth/). Python memory never reads or exposes your OAuth tokens.
